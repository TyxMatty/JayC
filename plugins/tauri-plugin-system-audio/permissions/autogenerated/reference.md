## Default Permission

Lets the app capture audio natively: other apps' sound for screen sharing, and the call microphone.

#### This default permission set includes the following:

- `allow-is-supported`
- `allow-list-audio-apps`
- `allow-list-mics`
- `allow-window-process`
- `allow-start-capture`
- `allow-stop-capture`
- `allow-start-mic`
- `allow-stop-mic`
- `allow-mic-call-state`
- `allow-jay-a-show`
