## Default Permission

Lets the app list audio-playing apps and capture their audio for screen sharing.

#### This default permission set includes the following:

- `allow-is-supported`
- `allow-list-audio-apps`
- `allow-window-process`
- `allow-start-capture`
- `allow-stop-capture`
